# Статические методы `:sin`, `:asin`, `:cos`, `:acos`, `:tan`, `:atan`, `:atan2`

Тригонометрические функции.

```parser3
^math:sin(радианы)
```
Синус.

```parser3
^math:asin(число)
```
Арксинус.
```parser3
^math:cos(радианы)
```
Косинус.
```parser3
^math:acos(число)
```
Арккосинус.
```parser3
^math:tan(радианы)
```
Тангенс.
```parser3
^math:atan(число)
```
Арктангенс.
```parser3
^math:atan2(число;число)
```
Четырехквадрантный арктангенс  ***[3.5.0]***

Методы вычисляют значения тригонометрических функций от заданного числа.

#### Пример
```parser3
^math:cos(^math:radians(180))
```

Получаем: **-1** (cos π = -1).
