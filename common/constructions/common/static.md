# Статические поля и методы

Вызов. Значения. Задание.

## Вызов статического метода

```parser3
^класс:метод[параметры]
```

Вызов статического метода класса.

> Точно так же вызываются динамические методы родительского класса (см. [Создание пользовательского класса](/common/constructions/common/class/)).

## Значение статического поля
```parser3
$класс:поле
```

Получение значения статического поля класса.

## Задание статического поля
```parser3
$класс:поле[значение]
```

Задание значения статического поля класса.
