# Метод `html`

Вывод изображения.

```parser3
^картинка.html[]
```
```parser3
^картинка.html[хеш]
```

Метод создает следующий HTML-тег:

```html
<img src="$image.src" width="$image.width" height="$image.height" border="0">
```

В качестве параметра методу может быть передан хеш, содержащий дополнительные атрибуты изображения, например `alt` и `border`, задающие надпись, которая появляется при наведении курсора, и ширину рамки.

> Атрибуты изображения можно переопределять.
> 
> Чтобы метод не выводил атрибут `border`, ему необходимо передать параметр `$.border[]` ***[3.4.1]***

#### Пример
```parser3
$photo[^image::measure[myphoto.jpg]]

^photo.html[
   $.border[0]
   $.alt[Это я в молодости…]
]
```
В браузере будет выведена картинка из переменной `$photo`. При наведении курсора на изображение будет появляться надпись: **Это я в молодости…**
