# Метод `delete`

Удаление пары «ключ / значение».

```parser3
^хеш.delete[ключ]
```
```parser3
^хеш.delete[]
```

Метод удаляет из хеша пару «ключ / значение». 

При вызове без параметра удаляются все поля хеша. ***[3.4.4]***

#### Пример
```parser3
^man.delete[name]
```

Удалит ключ name и связанное с ним значение из хеша man.
