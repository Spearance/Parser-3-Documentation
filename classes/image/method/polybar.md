# Метод `polybar`

Рисование окрашенных многоугольников по координатам узлов.

```parser3
^картинка.polybar(цвет)[координаты_узлов]
```

Метод рисует многоугольник заданного **цвета** по координатам узлов, задаваемым в таблице. Последний узел автоматически соединяется с первым.

#### Пример
```parser3
$coordinates[^table::create{x	y
0	0
50	70
100	0
}]

$square[^image::create(100;100;0x00FFFF)]
^square.polybar(0xFFFF00)[$coordinates]

$response:body[^square.gif[]]
```

В браузере будет выведен равнобедренный треугольник жёлтого цвета на голубом фоне. В таблице заданы координаты вершин треугольника.
