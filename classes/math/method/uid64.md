# Статический метод `:uid64`

64-битный уникальный идентификатор.

```parser3
^math:uid64[]
```
```parser3
^math:uid64[опции]
```

Метод выдает случайную строку вида: **BA39BAB6340BE370**

> В некоторых операционных системах метод выдает псевдослучайную строку.

Можно задать хеш опций: ***[3.4.6]***

`$.lower(false|true)` — выдавать результат в нижнем регистре, по умолчанию — в верхнем. См. `^[math](/class/math/):[uuid](/class/math/method/uuid/)[]`.
