# Метод `pop`

удаление и возврат последнего элемента массива

```parser3
^массив.pop[]
```
Метод удаляет последний инициализированный элемент массива и возвращает его значение.

#### Пример

```parser3
$data[name;age;gender]
$last[^data.pop[]]
```
Новое содержание массива `$data`:

```parser3
$man[name;age]
```
Значение переменной `$last`: `gender`.
