# Запись

Сохраняет на сервер ассоциацию между ключом и строкой.

```parser3
$memcached.ключ[значение]
```
```parser3
$memcached.ключ[
	$.value[значение]
	...необязательный модификатор...
]
```
Необязательный модификатор:

`$.expires(число_секунд)` — задает число секунд, на которое сохраняется пара «**ключ&thinsp;/&thinsp;строка**», **0** = навсегда.
