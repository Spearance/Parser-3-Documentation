# Методы `line-style` и `line-width`

Тип и ширина линий.

```parser3
$картинка.line-style[тип_линии]
```
```parser3
$картинка.line-width(толщина_линии)
```

Перед вызовом любых методов рисования допустимо задавать **тип** и **толщину** используемых линий. Тип линии задается строкой, где пробелы означают отсутствие точек в линии, а любые другие символы — их наличие.

> Ширина одного символа или пробела на изображении равна одному пикселю.

#### Пример
```parser3
$square[^image::create(100;100;0xFFBB00)]

$square.line-style[***   ]
$square.line-width(2)

^square.line(0;0;100;100;0xFFFFFF)

$response:body[^square.gif[]]
```
Для методов рисования будет использоваться пунктирная линия, толщиной в два пикселя, вида:
