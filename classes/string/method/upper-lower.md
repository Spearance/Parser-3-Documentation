# Методы `upper`, `lower`

Преобразование регистра строки.

```parser3
^строка.upper[]
```
```parser3
^строка.lower[]
```

Методы переводят строку в верхний `upper` или нижний `lower` регистр соответственно. Для их работы необходимо, чтобы был задан `[$request:charset](/class/request/field/charset/)`.

#### Пример
```parser3
$str[Москва]
^str.upper[]
```
Вернет: **МОСКВА**.
