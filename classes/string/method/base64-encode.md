# Метод `base64`

Кодирование в Base64.

```parser3
^строка.base64[]
```
```parser3
^строка.base64[опции]
```

Метод позволяет преобразовать строку в формат Base64. Для обратного преобразования строки из Base64 в исходный вид нужно воспользоваться `^string:[base64](/class/string/method/base64/)[закодированное]`.

Можно задать хеш опций: ***[3.4.6]***

`$.wrap(true|false)` — Формировать результат с переносами строк (по умолчанию) или в одну строку.  
`$.url-safe(false|true)` — Использовать модифицированный алфавит, все символы которого не будут преобразовываться в %XX в URL (вместо `+` и `/` используются `-` и `\_`). По умолчанию — не использовать.  
`$.pad(true|false)` — Добавлять символы [паддинга](https://en.wikipedia.org/wiki/Base64) (=), если кодируемая длина не кратна 3. По умолчанию — добавлять.  

Подробная информация о Base64 доступна по ссылкам: [ietf.org/rfc/rfc2045.txt](http://www.ietf.org/rfc/rfc2045.txt) и [wikipedia.org/wiki/Base64](https://en.wikipedia.org/wiki/Base64).

#### Пример
```parser3
$original[§ 1973. Ходят слухи, что «Зеленые рукава» написал сам…]
<pre>^original.base64[]</pre>
```
Выведет: **pyAxOTczLiDV7uT/8iDx6/P16Cwg9/LuIKvH5evl7fvlIPDz6uDi4Lsg7eDv6PHg6yDx4OyF**
