# Метод `sub`

Вычитание хешей.

```parser3
^хеш.sub[хеш-вычитаемое]
```

Метод вычитает из хеша другой хеш-вычитаемое, удаляя ключи, общие для обоих хешей.

#### Пример
```parser3
$man[
	$.name[Вася]
	$.age[22]
	$.gender[m]
]

$woman[
	$.name[Маша]
	$.age[20]
]

^man.sub[$woman]
```
В результате в хеше `$man` останется только один ключ `$man.gender` со значением **m**.
