# Метод `for`

Перебор всех элементов массива.

```parser3
^массив.for[индекс;значение]{тело}
```
```parser3
^массив.for[индекс;значение]{тело}[разделитель]
```
```parser3
^массив.for[индекс;значение]{тело}{разделитель}
```

Метод перебирает все элементы массива, включая неинициализированные («дырки»). Он аналогичен методу `[foreach](/class/array/method/foreach/)`, но итерируется по всем индексам массива.

### Пример
```parser3
$man[Вася;22;m]
^man.delete(1)

^man.for[key;value]{
	$key = $value
}[<br>]
```
Выведет:
**0 = Вася**
**1 = **
**2 = m**
