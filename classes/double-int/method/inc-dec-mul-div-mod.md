# Методы `inc`, `dec`, `mul`, `div`, `mod`

Простые операции над числами.

```parser3
^имя.inc[]
```
Увеличивает значение переменной на `1`.
```parser3
^имя.inc(число)
```
Увеличивает значение переменной на число.

```parser3
^имя.dec[]
```
Уменьшает значение переменной на `1`.
```parser3
^имя.dec(число)
```
Уменьшает значение переменной на число.

```parser3
^имя.mul(число)
```
Умножает значение переменной на число.

```parser3
^имя.div(число)
```
Делит значение переменной на число.

```parser3
^имя.mod(число)
```
Помещает в переменную остаток от деления ее значения на число.

#### Пример

```parser3
$var(5)
^var.inc(7)
^var.dec(3)
^var.div(4)
^var.mul(2)
$var
```
Пример возвратит `4.5` и эквивалентен записи `$var((5+7-3)/4*2)`.
