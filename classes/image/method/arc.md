# Метод `arc`

Рисование дуги.

```parser3
^картинка.arc(центр_x;центр_y;ширина;высота;начало_в_градусах;окончание_в_градусах;цвет)
```
   
Метод рисует дугу с заданными параметрами. Дуга представляет собой часть эллипса (как частный случай окружности) и задается координатами центра **X** и **Y**, **шириной**, **высотой**, а также **начальным** и **конечным углами**, измеряемыми в градусах.

#### Пример
```parser3
$square[^image::create(100;100;0xFF2200)]

^square.arc(50;50;40;40;0;90;0xFFFFFF)

$response:body[^square.gif[]]
```
В браузере будет выведен красный квадрат с дугой в четверть (от `0` до `90` градусов) окружности радиусом `40` пикселей.
