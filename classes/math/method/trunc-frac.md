# Статические методы `:trunc`, `:frac`

Операции с целой/дробной частью числа.

```parser3
^math:trunc(число)
```
Метод возвращает целую часть числа.

```parser3
^math:frac(число)
```
Метод возвращает дробную часть числа.

#### Пример
```parser3
^math:trunc(85.506)
```
Получаем: **85**

```parser3
^math:frac(85.506)
```
Получаем: **0.506**
