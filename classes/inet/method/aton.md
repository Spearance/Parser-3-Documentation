# Статический метод `:aton`

Преобразование строки с IP-адресом в число (Address To Number).

```parser3
^inet:aton[строка]
```

Метод преобразует в число переданную строку с IP-адресом. Метод аналогичен функции **inet_aton** MySQL-сервера и Perl.

#### Пример
```parser3
^inet:aton[10.0.0.2]
```

Получаем число **167772162**.
