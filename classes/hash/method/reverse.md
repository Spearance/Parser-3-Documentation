# Метод `reverse`

Обратный порядок элементов. ***[3.4.6]***

```parser3
^хеш.reverse[]
```

Метод возращает новый хеш, в котором элементы идут в порядке, обратном порядку добавления элементов в исходный хеш.

#### Пример

```parser3
$man[
	$.name[Вася]
	$.age[22]
	$.gender[m]
]

$man[^man.reverse[]]

^man.foreach[key;value]{
	$key = $value
}[<br>]
```

Выведет на экран:
`gender = m`
`age = 22`
`name = Вася`
