# Использование Parser в качестве интерпретатора скриптов

&nbsp;

```
/путь/к/parser3 [опции] файл_со_скриптом
```
```
x:\путь\к\parser3 [опции] файл_со_скриптом
```
Выполнять скрипты можно и без веб-сервера, достаточно запустить интерпретатор Parser, передав ему в командной строке параметр — имя скрипта. При этом корнем веб-пространства считается текущий каталог.

Доступные опции:

```
-f /path/to/auto.p
```
[Конфигурационный файл](/addition/install/common/config-file/) по умолчанию ищется в том же каталоге, где расположен интерпретатор Parser. С помощью этой опции можно указать другой путь к конфигурационному файлу.

```
-l /path/to/parser3.log
```
Об [ошибках](/common/operators/common/unhandled-exception/) Parser делает записи в [журнал ошибок](/class/status/field/log-filename/) **parser3.log**, который по умолчанию расположен в том же каталоге, где и сам интерпретатор Parser. С помощью этой опции можно изменить расположение журнала ошибок.

На UNIX можно также использовать стандартный подход с заданием команды запуска интерпретатора в первой строке скрипта:

```
#!/путь/к/parser3
# ваш код
Проверка: ^eval(2*2)
```

> Следует установить биты атрибута, разрешающие исполнение владельцу и группе. Команда: `chmod ug+x файл`
