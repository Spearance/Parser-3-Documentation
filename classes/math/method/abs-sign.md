# Статические методы `:abs`, `:sign`

Операции со знаком.

Методы выполняют операции со знаком числа.

```parser3
^math:abs(число)
```
Возвращает абсолютную величину числа (модуль).

```parser3
^math:sign(число)
```
Возвращает `1`, если число положительное, `-1`, если число отрицательное, и `0`, если число равно `0`.

#### Пример
```parser3
^math:abs(-15.506)
```
Получаем: **15.506**

```parser3
^math:sign(-15.506)
```
Получаем: **-1**
