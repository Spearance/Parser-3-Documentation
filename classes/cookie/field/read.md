# Чтение

значения существующего `cookie`.

```parser3
$cookie:имя_cookie
```

Возвращает значение `cookie` с указанным именем.

> Записанные значения доступны для чтения сразу.

Если указанного имени в списке `cookie` нет — вернет пустое значение.

#### Пример

```parser3
$cookie:my_cookie
```

Считывается и выдается значение `cookie` с именем `my_cookie`.
