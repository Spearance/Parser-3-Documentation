# Метод `format`

Вывод числа в заданном формате.

```parser3
^строка.format[форматная_строка]
```

Метод выводит значение переменной в заданном формате (см. «[Приложение 2. Форматные строки преобразования числа в строку](/addition/parts/common/format-string/)»). Выполняется автоматическое преобразование строки в число.

#### Пример
```parser3
$var[15.67678678]
^var.format[%.2f]
```
Возвратит: **15.68**
