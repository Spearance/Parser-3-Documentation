# Метод `length`

Получение длины надписи в пикселях.

```parser3
^картинка.length[текст_надписи]
```

Метод вычисляет полную длину надписи в пикселях.

#### Пример
```parser3
$square[^image::create(100;100;0x00FF00)]

^square.font[1234567890;digits.gif](8)

^square.length[1 128 500]
```

В результате вычислений длины надписи `1 128 500` в пикселях, с учетом пробелов и шрифтом из описания метода «[font](/class/image/method/font/)», вернет: **176**.
