## Краткое описание

[JSON](https://www.json.org/json-ru.html) — это альтернатива традиционным форматам (обычному тексту или XML), которые используются при обмене данными между сервером и клиентом. В отличие от XML и XML-совместимых языков, которые требуют синтаксического анализа, определения JSON могут быть просто включены в сценарии JavaScript. JSON также является текстовым форматом обмена данными и может довольно легко читаться людьми.

*[XML]: eXtensible Markup Language
*[JSON]: JavaScript Object Notation
