## Краткое описание

Класс имеет статические поля, доступные только для чтения.

Для проверки заполнения формы и редактирования имеющихся записей из базы данных удобно использовать такой подход:

```parser3
^if($edit){
	^rem{ запись из базы }
	$record[^table::sql{… WHERE id=…}]
}{
	^rem{ новая запись, ошибка при заполнении, необходимо вывести поля формы }
	$record[$form:fields]
}

<input name="age" value="$record.age">
```
