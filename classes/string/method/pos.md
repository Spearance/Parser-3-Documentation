# Метод `pos`

Получение позиции подстроки.

```parser3
^строка.pos[подстрока]
```
```parser3
^строка.pos[подстрока](позиция_начала_поиска)
```

Метод возвращает число `int` — позицию первого символа подстроки в строке (начиная с нуля), или **-1**, если подстрока не найдена. Если задана позиция начала поиска ***[3.3.0]***, то поиск подстроки будет начинаться с указанной позиции.


#### Примеры
```parser3
$str[полигон]
^str.pos[гон]
```
Вернет: **4**

```parser3
$str[полигон]
^str.pos[о](2)
```
Вернет: **5**
