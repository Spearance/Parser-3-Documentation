# Конструктор `::create`

Копирование даты ***[3.3.0]***

```parser3
^date::create[объект_класса_date]
```

Копирует объект класса `date`.

#### Пример

```parser3
$now[^date::now[]]

$dt[^date::create[$now]]

^dt.roll[month](-1)
```

В примере, в переменной `$dt`, получается дата, на месяц раньше текущей.
