# Метод `bar`

Рисование закрашенных прямоугольников.

```parser3
^картинка.bar(x0;y0;x1;y1;цвет)
```

Метод рисует на изображении закрашенный заданным цветом прямоугольник по заданным координатам.

#### Пример
```parser3
$square[^image::create(100;100;0x0000FF)]

^square.bar(5;40;95;60;0xFF00FF)

$response:body[^square.gif[]]
```
В браузере будет выведен синий квадрат размером **100×100** пикселей, внутри которого находится розовый прямоугольник **90×20** пикселей, нарисованный по заданным координатам.
