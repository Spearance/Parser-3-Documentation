# Метод `line`

Рисование линии на изображении.

```parser3
^картинка.line(x0;y0;x1;y1;цвет)
```

Метод рисует на изображении линию заданного цвета от точки с координатами `х0:y0` до точки `x1:y1`.

#### Пример
```parser3
$square[^image::create(100;100;0x005FFF)]
^square.line(0;100;100;0;0xFFFFFF)

$response:body[^square.gif[]]
```
В браузере будет выведен синий квадрат размером **100×100** пикселей, перечеркнутый по диагонали белой линией.
