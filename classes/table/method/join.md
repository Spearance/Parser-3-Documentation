# Метод `join`

Объединение двух таблиц.

```parser3
^таблица1.join[таблица2]
```
```parser3
^таблица1.join[таблица2;опции]
```

Метод добавляет в конец **таблицы1** записи из **таблицы2**. При этом берутся значения из тех столбцов **таблицы2**, имена которых совпадают со столбцами **таблицы1**, остальные столбцы будут содержать пустые строки. Также можно задать ряд опций, контролирующих добавление, см. «[Опции копирования и поиска](/class/table/options/copy-search/)».

#### Пример
```parser3
^stuff.join[$just_hired_people]
```

Все записи таблицы `$just_hired_people` будут добавлены в таблицу `$stuff`.
