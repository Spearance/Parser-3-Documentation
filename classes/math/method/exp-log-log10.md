# Статические методы `:exp`, `:log`, `:log10`

Логарифмические функции.

Методы вычисляют значения логарифмических функций от заданного числа.

```parser3
^math:exp(число)
```
Экспонента **числа** по основанию **e**.

```parser3
^math:log(число)
```
Натуральный логарифм **числа**.

```parser3
^math:log10(число)
```
Десятичный логарифм **числа**.


> Логарифм по произвольному основанию base вычисляется как log(число)/log(base).
