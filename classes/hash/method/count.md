# Метод `count`, `_count`

Количество ключей хеша.

```parser3
^хеш._count[]
```
```parser3
^хеш.count[]
```
> Метод `count` доступен начиная с версии ***[3.4.4]***

Метод возвращает количество ключей хеша.

#### Пример
```parser3
$man[
	$.name[Вася]
	$.age[22]
	$.gender[m]
]
^man.count[]
```

Вернет: `3`.

В выражениях числовое значение хеша равно количеству ключей:
```parser3
^if($man > 2){больше}
```
