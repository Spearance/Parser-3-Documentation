# Статический метод `:filename`

Получение имени файла. ***[3.4.5]***

```parser3
^reflection:filename[класс_объект_или_метод]
```

Метод возвращает полный дисковый путь к файлу, в котором определен класс или метод. Для объекта возвращается путь к файлу, в котором определен его класс.

> В случае partial-классов возвращается путь к первому файлу, в котором определен класс.
