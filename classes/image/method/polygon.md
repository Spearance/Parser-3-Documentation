# Метод `polygon`

Рисование неокрашенных многоугольников по координатам узлов.

```parser3
^картинка.polygon(цвет линии)[таблица с координатами узлов]
```

Метод рисует линией заданного цвета многоугольник по координатам узлов, задаваемым в таблице. Последний узел автоматически соединяется с первым.

#### Пример
```parser3
$coordinates[^table::create{x	y
20	20
50	80
80	20
}]

$square[^image::create(100;100;0x333333)]
^square.polygon(0x00FF00)[$coordinates]

$response:body[^square.gif[]]
```
В браузере будет выведен равнобедренный треугольник, нарисованный линией зеленого цвета на сером фоне. В таблице заданы координаты вершин треугольника.
