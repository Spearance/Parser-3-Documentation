# Метод `cleanup`

Удаление устаревших записей.

```parser3
^hashfile.cleanup[]
```

Метод перебирает все пары и удаляет устаревшие.

> Физического удаления из файла не происходит. Устаревшие пары лишь помечаются как удаленные, и последующие записи новых данных могут использовать освободившееся место.
