# Статический метод `:dirname`

Путь к файлу.

```parser3
^file:dirname[filespec]
```

Для переданного файла или каталога `filespec` метод возвращает каталог, в котором он находится.

#### Пример
```parser3
# имя файла
^file:dirname[/a/some.tar.gz]
```
```parser3
# имя каталога…
^file:dirname[/a/b/]
```

Оба вызова возвратят: **/a**
