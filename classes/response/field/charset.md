# Статическое поле `charset`

Задание кодировки ответа.

```parser3
$response:charset[кодировка]
```

Задает кодировку ответа. После обработки запроса результат переводится в эту кодировку.

По умолчанию используется кодировка **UTF-8**.

Список допустимых кодировок определяется [Конфигурационным методом](/addition/install/common/config-method/). 

Рекомендуется определять кодировку документов в [Конфигурационном файле](/addition/install/common/config-file/).

См. также «[Задание кодировки документов на сервере](/class/request/field/charset/)».
