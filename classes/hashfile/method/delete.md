# Метод `delete`

Удаление пары «ключ / значение».

```parser3
^hashfile.delete[ключ]
```

Метод удаляет из файла пару «ключ / значение».

> Физического удаления из файла не происходит. Пара с указанным ключом лишь помечается как удаленная, и последующая запись новых данных может использовать освободившееся место.
