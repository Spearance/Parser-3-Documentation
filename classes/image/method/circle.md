# Метод `circle`

Рисование неокрашенной окружности.

```parser3
^картинка.circle(центр_x;центр_y;радиус;цвет_линии)
```

Метод рисует окружность заданного радиуса линией заданного цвета относительно центра с координатами **X** и **Y**.

#### Пример
```parser3
$square[^image::create(100;100;0xFF7700)]

^square.circle(50;50;10;0xFFFFFF)

$response:body[^square.gif[]]
```
В браузере будет выведен оранжевый квадрат с окружностью радиусом в **10** пикселей, нарисованной линией белого цвета с центром в точке **50;50**:
