# Статические поля `body-charset`, `post-charset`

Получение кодировки пришедшего POST-запроса. ***[3.3.0]***

```parser3
$request:post-charset
```
```parser3
$request:body-charset
```

Если в HTTP-заголовке content-type пришедшего POST-запроса содержится информация о кодировке, то ее название доступно в этом поле. При разборе полей формы подобного POST-запроса данные перекодируются из указанной в этом заголовке кодировки ***[3.4.4]***, а не из того, что задано в `[$response:charset](/class/response/field/charset/)`.

> Если кодировка, указанная в упомянутом HTTP-заголовке, не была подключена (например, в конфигурационном методе), то будет выдано сообщение об ошибке.
