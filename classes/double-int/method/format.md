# Метод `format`

Вывод числа в заданном формате.

```parser3
^имя.format[форматная_строка]
```

Метод выводит значение переменной в заданном формате (см. [Приложение 2. «Форматные строки»](/addition/parts/common/format-string/)).

Если не пользоваться `format` и выводить число просто так: `$имя` то это эквивалентно `^имя.format[%.15g]`. Такое форматирование автоматически выбирает наиболее подходящий вид: числа будут выведены в обычном формате, если это возможно, а очень малые (меньше 1e-05) или очень большие (больше 1e+15) числа — в экспоненциальном формате.

#### Примеры

```parser3
$var(15.67678678)
^var.format[%.2f]
```
Возвратит: **15.68**

```parser3
$var(0x123)
^var.format[0x%04X]
```
Возвратит: **0x0123**
