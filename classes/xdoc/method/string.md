# Метод `string`

Преобразование документа в строку.

```parser3
^документ.string[]
```
```parser3
^документ.string[Параметры_преобразования_в_текст]
```

Метод преобразует **документ** в текстовую форму. Возможно задание **параметров_преобразования**.
По умолчанию создается XML-представление документа с заголовком `<?xml … ?>` (можно отключить вывод заголовка, задав [соответствующий параметр](/class/xdoc/options/convert-to-text/)).

Результат выдается посетителю as-is.

#### Пример
```parser3
$document[^xdoc::create{<?xml version="1.0" encoding="windows-1251" ?>
<document>
	строка1<br />
	строка2<br />
</document>}]

^document.string[
	$.method[html]
]
```
