# Конструктор `::open`

Открытие или создание.

```parser3
^hashfile::open[имя_файла]
```

Открывает имеющийся на диске файл или создает новый.

Для хранения данных `hashfile` используются два файла — с расширениями `.dir` и `.pag`

> В один момент времени файл может изменяться только одним скриптом, остальные ждут окончания его работы. Перед началом изменений скрипт ожидает, чтобы все остальные скрипты перестали читать этот файл.
> 
> Нельзя два раза открыть один и тот же файл.
