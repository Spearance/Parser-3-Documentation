# Статический метод `:sql`

Запрос к БД, не возвращающий результата.

```parser3
^void:sql{SQL-запрос}
```
```parser3
^void:sql{SQL-запрос}[
	$.bind[variables_hash]
]
```

Метод выполняет SQL-запрос, который не возвращает результат (операции по управлению данными в базе данных). Для работы этого метода необходимо установленное соединение с сервером базы данных (см. оператор [connect](/common/operators/common/connect/)).

Возможно использование дополнительного параметра конструктора:

`$.bind[hash]` — связанные переменные, см. «[Работа с IN/OUT-переменными](/addition/parts/common/in-out/)».

#### Пример
```parser3
^connect[строка подключения]{
	^void:sql{
		CREATE TABLE users (id int, name text, email text)
	}
}
```
В результате выполнения этого кода в базе данных будет создана таблица **users**, при этом запрос не вернет никакого результата. Пример дан для СУБД MySQL. 

*[БД]: База данных
*[СУБД]: Система управления базами данных
