# Метод `rectangle`

Рисование незакрашенных прямоугольников.

```parser3
^картинка.rectangle(x0;y0;x1;y1;цвет_линии)
```

Метод рисует на изображении незакрашенный прямоугольник по заданным координатам с заданным цветом линии.

#### Пример
```parser3
$square[^image::create(100;100;0x05555F)]
^square.rectangle(5;40;95;60;0xF3F3FF)

$response:body[^square.gif[]]
```

В браузере будет выведен сине-зеленый квадрат размером **100×100** пикселей, внутри которого находится прямоугольник **90×20** пикселей, нарисованный линией светло-серого цвета по заданным координатам.
