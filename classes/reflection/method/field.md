# Статический метод `:field`

Получение значения поля объекта. ***[3.4.2]***

```parser3
^reflection:field[объект;имя_поля]
```
```parser3
^reflection:field[класс;имя_поля]
```

Метод возвращает поле объекта или класса. Работает с пользовательскими и некоторыми системными классами.

> Поиск полей по иерархии классов не производится.
