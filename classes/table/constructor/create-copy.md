# Конструктор `create`

Копирование существующей таблицы.

```parser3
^table::create[таблица]
```
```parser3
^table::create[таблица;опции]
```

Конструктор создает объект класса `table`, копируя данные из другой таблицы. Также можно задать ряд опций, контролирующих копирование (см. «[Опции копирования и поиска](/class/table/options/copy-search/)»).

#### Пример
```parser3
$orig[^table::create{name
Вася
Коля
Маша
}]

# сдвигает текущую запись таблицы orig на «Коля»
^orig.offset(1)

# копирует, начиная с текущей записи в orig, не больше 10 записей
$copy[^table::create[$orig;
	$.offset[cur]
	$.limit(10)
]]

^copy.menu{$copy.name}[, ]
```
Выведет: **Коля, Маша**
