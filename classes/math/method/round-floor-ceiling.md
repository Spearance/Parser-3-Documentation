# Статические методы `:round`, `:floor`, `:ceiling`

Округления.

```parser3
^math:round(число)
```
Округление до ближайшего целого.

```parser3
^math:floor(число)
```
Округление до целого в меньшую сторону.

```parser3
^math:ceiling(число)
```
Округление до целого в большую сторону.

Методы возвращают округленное значение заданного числа класса `double`.


#### Примеры
| Пример                | Результат |
|-----------------------|-----------|
| `^math:round(45.50)`  | 46        |
| `^math:floor(45.60)`  | 45        |
| `^math:ceiling(45.20)`| 46        |
| `^math:round(-4.5)`   | -4        |
| `^math:floor(-4.6)`   | -5        |
| `^math:ceiling(-4.20)`| -4        |
