# Метод `text`

Нанесение надписей на изображение.

```parser3
^картинка.text(x;y)[текст_надписи]
```

Метод выводит заданную надпись по указанным координатам (**X;Y**), используя файл шрифта, предварительно загруженный методом [font](/class/image/method/font/).

#### Пример
```parser3
$square[^image::create(270;45;0xFDBB9C)]
^square.font[1234567890;digits.gif](10)

^square.text(5;5)[2 143 576 890]

$response:body[^square.gif[]]
```

В браузере будет выведен розовый прямоугольник с надписью **2 143 576 890**, левая верхняя точка которой имеет координаты (**5;5**).
