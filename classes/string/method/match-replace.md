# Метод `match`

Замена подстроки, соответствующей шаблону.

```parser3
^строка.match[шаблон][опции_поиска]{замена}
```
```parser3
^строка.match[шаблон][опции_поиска][замена]
```
```parser3
^строка.match[шаблон][опции_поиска]{замена}{если_не_было_совпадений}
```

Метод осуществляет **поиск** в строке по **шаблону** и производит **замену** совпавшей подстроки на заданную. Механизм поиска устроен так же, как и у предыдущего [метода](/class/string/method/match/). Внутри кода замены доступна автоматически создаваемая таблица совпадений match, которая была рассмотрена выше.

> Возвращение результата, в случае если не было совпадений, доступно с версии ***[3.4.1]***

#### Пример
```parser3
$str[2002.01.01]
^str.match[(\d+)\.(\d+)\.(\d+)][g]{Год $match.1, месяц $match.2, число $match.3}
```
Выведет: **Год 2002, месяц 01, число 01**.
