# Статический метод `:ntoa`

Преобразование числа в строку с IP-адресом (Number To Address).

```parser3
^inet:ntoa(число)
```

Метод преобразует в число переданную строку с IP-адресом. Метод аналогичен функции **inet_ntoa** MySQL-сервера и Perl.

#### Пример
```parser3
^inet:ntoa(167772162)
```

Получаем строку **10.0.0.2**.
