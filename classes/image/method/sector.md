# Метод `sector`

Рисование сектора.

```parser3
^картинка.sector(центр_x;центр_y;ширина;высота;начало_в_градусах;окончание_в_градусах;цвет)
```

Метод рисует сектор с заданными параметрами линией заданного цвета. Параметры метода аналогичны методу `arc`.

#### Пример
```parser3
$square[^image::create(100;100;0x055330)]
^square.sector(50;50;40;40;30;320;0xFF2255)

$response:body[^square.gif[]]
```
В браузере будет выведен зелёный квадрат с сектором в четверть (от 30 до 320 градусов) окружности радиусом **40** пикселей. Сектор нарисован линией красного цвета.
