# Статическое поле `charset`

Задание кодировки документов на сервере.

```parser3
$request:charset[кодировка]
```

Задает **кодировку** документов, обрабатываемых на сервере. При обработке запроса считается, что в этой кодировке находятся все файлы на сервере.

По умолчанию используется кодировка **UTF-8**.

Список допустимых кодировок определяется Конфигурационным методом.

Рекомендуется определять кодировку документов в Конфигурационном файле.

См. также «[Задание кодировки ответа](/class/response/field/charset/)».
