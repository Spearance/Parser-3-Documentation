# Статическое поле `fields`

Все поля формы.

```parser3
$form:fields
```

Поле возвращает хеш со всеми элементами формы или параметрами, переданными через URL. Имена ключей хеша — это названия элементов формы, значениями ключей являются значения элементов формы.

#### Пример
```parser3
^form:fields.foreach[field;value]{
	$field — $value
}[<br>]
```

Пример выведет на экран все поля формы и соответствующие значения. Предположим, что URI страницы:

`www.mysite.ru/testing/index.html?name=dvoechnik&mark=2`

Тогда пример выдаст следующее:

**name — dvoechnik**
**mark — 2**
